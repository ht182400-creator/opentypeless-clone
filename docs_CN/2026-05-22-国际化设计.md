# 完整 UI 国际化（i18n）设计

**目标：** 用 i18next 的 `t()` 调用替换全部约 136 处硬编码的用户可见字符串，新增 8 种语言（ja、ko、fr、de、es、pt、ru、it），并让 Rust 系统托盘菜单响应所选的 UI 语言。

**架构：** 扩展已有的 i18next + react-i18next 配置。前端继续使用 `t()` 键。Rust 托盘菜单从 Tauri store 读取 `ui_language`，并从内置的 HashMap 中查找标签——无需外部 i18n 库。

**技术栈：** i18next、react-i18next、Tauri store、Rust HashMap

## 3. Rust 托盘菜单 i18n

### 3.1 托盘标签 HashMap

在 `src-tauri/src/tray.rs` 中新增函数 `get_tray_labels(lang: &str) -> TrayLabels`：

```rust
struct TrayLabels {
    show_window: &'static str,
    hide_window: &'static str,
    start_recording: &'static str,
    stop_recording: &'static str,
    settings: &'static str,
    history: &'static str,
    account: &'static str,
    about: &'static str,
    quit: &'static str,
}
```

用 `match` 语句将语言代码映射到带有静态 `&str` 值的 `TrayLabels` 结构体。未识别语言回退到英文。

### 3.2 菜单构建流程

1. `build_tray_menu()` 从 Tauri store 读取 `ui_language`（默认 `"en"`）
2. 调用 `get_tray_labels(&lang)` 获取翻译后的字符串
3. 将这些字符串用作菜单项标签

### 3.3 语言切换流程

1. 用户在前端选择语言（WelcomeStep 或 AboutPane）
2. 前端调用 `update_config({ ui_language: "ja" })` → 保存到 store
3. 前端调用 `invoke('refresh_tray_labels')`（新命令）
4. Rust 从 store 读取更新后的 `ui_language`，通过 `refresh_tray()` 重建菜单

### 3.4 新增命令

在 `commands/misc.rs` 中：

```rust
#[tauri::command]
fn refresh_tray_labels(app: tauri::AppHandle) -> Result<(), String> {
    refresh_tray(&app);
    Ok(())
}
```

在 `lib.rs` 的 invoke handler 中注册。

## 4. 不该翻译的内容

- `STT_PROVIDERS` / `LLM_PROVIDERS` 标签 —— 品牌名与专有名词
- `LANGUAGES` / `TARGET_LANGUAGES` —— 语言名称本身即固有内容
- `console.log` / `console.error` —— 仅开发者可见
- 技术标识符（配置键、provider ID）
