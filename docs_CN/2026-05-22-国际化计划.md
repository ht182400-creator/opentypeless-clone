# 完整 UI 国际化（i18n）实施计划

> **面向自动化执行人员：** 必须使用子技能 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 来按任务逐条实现本计划。步骤使用复选框（`- [ ]`）语法进行跟踪。

**目标：** 将约 136 处硬编码的用户可见字符串替换为 i18next 的 `t()` 调用，新增 8 种语言（ja、ko、fr、de、es、pt、ru、it），并让 Rust 托盘菜单响应所选的 UI 语言。

**架构：** 扩展现有的 i18next 配置。前端将硬编码字符串迁移为 `t()` 键。Rust 托盘菜单从 Tauri store 读取 `ui_language`，并通过内置的 HashMap 查找对应标签。前端在语言切换后通过新增的 `refresh_tray_labels` 命令触发托盘刷新。

**技术栈：** i18next、react-i18next、Tauri store、Rust HashMap

const fs = require('fs');
const en = JSON.parse(fs.readFileSync('src/i18n/locales/en.json','utf8'));
const langs = ['zh','ja','ko','fr','de','es','pt','ru','it'];
function getKeys(obj, prefix='') {
  return Object.entries(obj).flatMap(([k,v]) =>
    typeof v === 'object' ? getKeys(v, prefix+k+'.') : [prefix+k]
  );
}
const enKeys = new Set(getKeys(en));
for (const lang of langs) {
  const other = JSON.parse(fs.readFileSync('src/i18n/locales/'+lang+'.json','utf8'));
  const otherKeys = new Set(getKeys(other));
  const missing = [...enKeys].filter(k => !otherKeys.has(k));
  const extra = [...otherKeys].filter(k => !enKeys.has(k));
  if (missing.length || extra.length) {
    console.log(lang + ': missing ' + missing.length + ', extra ' + extra.length);
    if (missing.length) console.log('  missing:', missing.slice(0,5));
  } else {
    console.log(lang + ': OK (' + enKeys.size + ' keys match)');
  }
}
"
