# OpenTypeless v1.1.48

本次发布聚焦于让 OpenTypeless 在日常语音工作流中更快、更清晰、更可靠。

## 重点内容

- **Typeless 风格的热键**
  - macOS 听写现在默认使用 `Fn`。
  - Windows 听写现在默认使用 `Right Alt`。
  - Ask Anything 有独立快捷键：macOS 上为 `Fn+Space`，Windows 上为 `Right Alt+Space`。
  - Linux 仍使用 `Ctrl+/` 触发听写、`Ctrl+.` 触发 Ask Anything，因为在各 Linux 桌面环境下 Right Alt 的全局处理不够稳定。

- **Ask Anything 更轻盈**
  - Ask 现在通过胶囊（capsule）录音，而不再显示第二个录音面板。
  - 结果以紧凑的浮动便签呈现。
  - 答案可直接复制。
  - 点击便签外部即可关闭它。

- **更清爽的账户与升级体验**
  - 升级现在使用与 App 其余部分一致的安静产品 UI。
  - 定价、套餐状态与权益更易一览，无需增加额外的设置选项。

- **更顺滑的胶囊流程**
  - 胶囊现在有更清晰的准备中、录音中、转写中、润色中、Ask 录音中、Ask 思考中、输出中等状态。
  - 空闲胶囊的可见性可在通用设置、胶囊右键菜单或系统托盘中控制。

- **写作风格与场景**
  - 新增润色风格：极简（Minimal）、整洁（Clean）、结构化（Structured）、专业（Professional）。
  - 新增内置场景、本地自定义场景、场景激活元数据，以及导入/导出。
  - 场景让可复用的写作行为更易管理，而不必把设置页变成臃肿的编辑器。

- **选中文本工作流**
  - Ask 与润色可以使用选中文本作为上下文。
  - 出于隐私与成本考虑，选中文本会在发送给 AI 之前被截断。
  - App 更细致地区分"破坏性编辑"与"非破坏性提问"。

- **词典与纠错规则**
  - 自定义词典现在与本地纠错规则配对。
  - 这有助于修正反复出现的转写错误和领域特定短语。

- **更可靠的热键与输出**
  - 热键注册现在有更清晰的状态、冲突检查、重试行为与回滚。
  - 输出策略包括键盘模拟、剪贴板粘贴、仅复制兜底，以及 Windows SendInput。
  - 剪贴板恢复与输出诊断更安全、更易理解。

- **本地与 BYOK 改进**
  - 新增 macOS Apple Speech 作为内置本地语音 provider。
  - 改进自定义 Whisper/自托管 STT 诊断。
  - 在支持的系统上，BYOK 密钥存储在操作系统凭据保险库中。

## 说明

- 取决于发布 Secret，Windows 构建可能仍然未签名。
- macOS 与 Linux 发布产物预期使用已配置的签名密钥。
- 本版本的英文与中文界面文案已完整。其他内置语言文件覆盖了全部键，但部分较新的高级功能文案仍可能显示英文兜底文本。
- 云端仍为可选项。BYOK 以及本地/自托管路径在无需 OpenTypeless 云服务的情况下继续可用。
