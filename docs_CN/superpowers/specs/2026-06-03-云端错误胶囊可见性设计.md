# 云端 STT 错误与胶囊可见性修复设计

## 背景

Issue #46 在修复两条崩溃/冻结路径后关闭：

- 点击录音胶囊取消按钮不再冒泡到外层胶囊的停止处理器；
- 云端 STT 缓冲在等待基于上传的转写时不再忙等自旋。

一次后续的手工测试暴露出仍存在的用户侧失败模式。一次云端 STT 请求从 `/api/proxy/stt` 返回 HTTP 403，但桌面胶囊随后显示 `No speech detected. Please try again.`（未检测到语音，请重试）。这掩盖了真实原因，让 quota/auth 失败看起来像麦克风或静音问题。

桌面胶囊还有一个已有的 `capsule_auto_hide` 设置，但右键胶囊菜单没有暴露它。除非用户发现设置页，否则会看到一个常驻的桌面麦克风图标。

## 当前证据

- 云端 STT provider 把来自云端 STT 端点的每个 HTTP 403 映射为 `AppError::Auth`。
- 当前云端 403 回退文案是 `STT quota exceeded`；这会让空或不可解析的 403 body 看起来像 quota 失败。
- `AppError::Auth` 映射为前端错误码 `stt_invalid_key`。
- STT 任务可以发出一个 STT 错误，然后 `wait_for_stt()` 看到累积转写为空，发出纯字符串 `No speech detected. Please try again.`。
- 前端已支持结构化的 `pipeline:error` 负载，形态为 `{ code, details, retry_count }`，但 locale 文件当前未在 `errors` 下定义 STT 错误码。
- `capsule_auto_hide` 已存在于 Rust 存储与前端状态中。
- 主窗口与胶囊窗口各自维护自己的 Zustand 状态。胶囊窗口在启动时加载一次配置，因此对它使用完整 config 对象做持久化可能覆盖从主窗口保存的较新设置。
- `useCapsuleResize()` 仅在 `becameIdle` 时隐藏胶囊、仅在 `leftIdle` 时显示它。它不处理“仍空闲、刚启用自动隐藏”或“仍空闲、刚出现错误”的情况。
- 系统托盘当前从 `settings.json` 的顶层读取 `ui_language`，而配置保存在 `app_config.ui_language` 下。
- 设置的 dirty-bar（未保存提示栏）保存路径调用完整的 `update_config`，但该 Rust 命令当前只保存；它不在语言变更后把配置变更广播给胶囊 webview 或刷新托盘标签。
- `CapsuleRecording` 已通过 `audioVolume` 显示音量驱动的波形条。
- `DurationTimer` 已显示录音时长并在达到配置上限时自动停止。
- `CapsuleProcessing` 与 `CapsulePolishing` 已分别表示转写/思考状态。

## 目标

1. 在桌面 UI 中保留真实的云端 STT 失败原因。
2. 区分云端 STT quota 耗尽与无效的 auth/session 错误。
3. 让“无语音”成为一种结构化的、本地化的错误，仅在 STT 确实以空文本成功时才显示。
4. 为新增与已有的 STT 错误码补齐完整的 locale 覆盖。
5. 让用户能从胶囊右键菜单隐藏空闲的桌面胶囊。
6. 在录音、转写、润色、输出、上下文菜单展示，以及短时的错误展示期间保持胶囊可见。
7. 当空闲胶囊被隐藏且右键菜单不可达时，给用户一条恢复路径。
8. 在不覆盖无关未保存设置的情况下，跨主窗口与胶囊 webview 同步胶囊可见性变更。
9. 支持新安装默认隐藏，同时不静默改变已有用户持久化的偏好。

## 非目标

- 不要在本桌面端修复中重设云端 quota 策略或改变服务端 quota 预留量。
- 不要替换现有的波形、计时器、转写、润色或输出胶囊组件。
- 不要移除系统托盘图标；它仍是访问设置、历史、录音、退出的永远可用入口。
- 不要创建第二个重复 `capsule_auto_hide` 的设置。
- 不要让胶囊菜单持久化整个 config 对象。
- 不要强迫刻意保持胶囊可见的已有用户进入自动隐藏。

## 推荐方案

复用现有的 `capsule_auto_hide` 配置，但改变它的切换与同步方式。

胶囊与托盘菜单不应调用通用的完整 config `update_config` 命令。它们应调用一个专用的部分命令，该命令从 Rust 存储加载最新配置、只更新 `capsule_auto_hide`、保存它，并广播一个 patch 事件。

这保留了现有行为模型，让功能可被发现，并避免陈旧 webview 状态覆盖较新设置。

被否决的替代方案：

- 在没有设置的情况下空闲时总是隐藏胶囊。这移除了用户控制权，让功能更难被发现。
- 把设置只保留在设置页。这保留了当前糟糕的可发现性。
- 创建单独的“桌面图标已隐藏”标志。这会重复 `capsule_auto_hide` 并带来状态冲突风险。
- 让胶囊菜单持久化完整 config 对象。胶囊窗口可能持有陈旧 config 并覆盖别处更改的设置。

## 期望行为

### 云端 STT 错误

当云端 STT 收到 HTTP 403：

- 若响应带有稳定的 quota 码（如 `quota_exceeded` 或 `stt_quota_exceeded`），桌面端发出 `stt_quota_exceeded`。
- 若没有稳定码，但响应错误信息明确包含 quota 耗尽措辞，桌面端发出 `stt_quota_exceeded`。
- 若 body 为空、不可解析，或不能明确指示 quota 耗尽，桌面端发出 `stt_invalid_key`，附带通用的访问被拒详情。
- 前端渲染本地化的 `errors.<code>` 消息。
- 管线对同一个录音会话之后不再发出 `stt_no_speech_detected`。

当云端 STT 成功但返回空文本：

- 桌面端发出 `stt_no_speech_detected`。
- 错误是本地化的。
- 该消息保留给真实的静音或不可懂音频，而非 quota/auth/网络失败。

### 胶囊可见性

胶囊窗口的期望可见性必须在每次相关输入变化时由状态计算：

```ts
const shouldShowCapsule =
  !capsuleAutoHide ||
  contextMenuOpen ||
  capsuleExpanded ||
  hasError ||
  pipelineState !== 'idle'
```

当 `capsule_auto_hide` 启用时：

- 空闲且无错误、无菜单、无展开：胶囊窗口隐藏；
- 录音中：胶囊窗口显示波形、录音时长与取消操作；
- 转写中：胶囊窗口显示转写状态与（可用时的）部分转写；
- 润色中：胶囊窗口显示思考状态；
- 输出中：胶囊窗口短暂显示完成状态；
- 错误：胶囊窗口短暂显示本地化错误，然后回到空闲隐藏状态；
- 打开上下文菜单会保持胶囊窗口可见，直到菜单关闭。

当 `capsule_auto_hide` 禁用时：

- 空闲胶囊作为小麦克风胶囊保持可见。

状态转换必须包含这些情形：

- 在已空闲时启用自动隐藏：菜单关闭后隐藏胶囊；
- 在已空闲时禁用自动隐藏：显示胶囊；
- 在已空闲时收到错误：显示胶囊；
- 在已空闲且自动隐藏启用时清除错误：隐藏胶囊。

### 菜单与恢复

胶囊右键菜单：

- 当 `capsule_auto_hide` 禁用时显示 `Hide capsule when idle`（空闲时隐藏胶囊）；
- 当 `capsule_auto_hide` 启用时显示 `Keep capsule visible`（保持胶囊可见）；
- 调用专用的 `set_capsule_auto_hide(enabled)` Tauri 命令；
- 不调用完整 config 的 `update_config` 命令；
- 命令成功后关闭；
- 若在空闲且无错误时切换为开启，关闭后立即隐藏胶囊；
- 若在空闲时切换为关闭，立即显示胶囊。

系统托盘菜单：

- 新增同样的胶囊可见性切换作为恢复路径；
- 调用与 Tauri 命令相同的 Rust 辅助；
- 即使桌面胶囊被隐藏也保持可用；
- 从 `app_config.ui_language` 读取语言。

设置页：

- 保留现有的 `Hide capsule when idle` 开关与 dirty-bar 保存流程；
- 在右键或托盘切换后通过 config patch 事件保持同步；
- 通过 dirty-bar 保存设置时，也广播影响其他 webview 的持久化配置字段；
- 当外部胶囊可见性 patch 到达时，保留无关的 dirty 设置。

默认行为：

- 没有存储 `app_config` 的全新安装，默认 `capsule_auto_hide` 为 `true`；
- 已有显式 `capsule_auto_hide` 的存储配置保留该值；
- 缺失 `capsule_auto_hide` 的已有存储配置，该单字段默认 `false`，保留历史“空闲可见”行为；
- 前端默认值应匹配新安装默认值，但加载的 Rust 配置才是事实来源。

引导（Onboarding）：

- 若新安装默认空闲时隐藏，引导文案必须说明胶囊在录音时会出现，并可从托盘/设置恢复。
- 完成步骤不得暗示空闲胶囊总是可见且可点击。

## 架构

### Rust 错误模型

新增一个显式的 quota 错误变体：

- `AppError::Quota(String)`

映射：

- `Quota` 不可重试。
- `Quota` 映射为 `UserError { code: "stt_quota_exceeded", details, retry_count: 0 }`。
- 401 与非 quota 的 403 继续映射为 `stt_invalid_key`。

云端 STT 应使用一个可测试的辅助，例如：

```rust
fn cloud_stt_forbidden_error(body: &str) -> AppError
```

分类顺序：

1. 解析 JSON 并检视稳定字段，如 `code`、`error_code` 或 `type`。
2. 若稳定字段表示 quota 耗尽，返回 `AppError::Quota`。
3. 否则检视 `error` 或 `message` 文本中的 quota 耗尽措辞。
4. 若仍不明确表示 quota，返回 `AppError::Auth("Cloud STT access denied".to_string())`（云端 STT 访问被拒）。

该辅助绝不可把空或不可解析的 body 默认判为 quota。

### 管线错误锁存（Latching）

跟踪当前会话最后一次 STT 失败。一旦发出 STT provider 错误，`wait_for_stt()` 不得为同一会话发出无语音。

使用一个感知会话的值，例如：

```rust
Arc<Mutex<Option<(u64, UserError)>>>
```

规则：

- 当一次新录音成功从 idle 转换到 recording 时，清除锁存值；
- 仅在 `should_finalize_stt_task(...)` 返回 true 后设置锁存值；
- `wait_for_stt(stt_control)` 只消费会话 id 与当前 `stt_control` 匹配的锁存错误；
- 陈旧任务不得为更新的会话锁存错误；
- 真实空的成功 STT 仍可发出 `stt_no_speech_detected`。

### 前端 i18n

若缺失，为每个 locale 文件新增一个 `errors` 对象。至少包含：

- `stt_timeout`
- `stt_invalid_key`
- `stt_failed`
- `stt_quota_exceeded`
- `stt_no_speech_detected`
- `output_fallback_clipboard`

前端应暂时继续兼容纯字符串错误以保持兼容，但新的后端 STT 错误应使用结构化负载。

### 胶囊可见性命令与同步

新增一个专用 Tauri 命令：

```rust
set_capsule_auto_hide(enabled: bool) -> Result<(), String>
```

该命令应：

- 从 `ConfigManager` 加载最新配置；
- 只更新 `capsule_auto_hide`；
- 保存配置；
- 向所有打开的 webview 发出携带 `{ "capsule_auto_hide": enabled }` 的 `config:patch` 事件；
- 刷新托盘标签/菜单。

托盘菜单应在内部调用相同的 Rust 辅助，而不是重复保存逻辑。

更新现有的完整 `update_config` 命令在保存之后：

- 在覆盖缓存前比较先前的持久化配置与新配置；
- 当发生变更时，为影响胶囊或托盘的持久化字段发出 `config:patch`，至少包含变更时的 `capsule_auto_hide`、`max_recording_seconds` 与 `ui_language`；
- 当 `ui_language` 变更时刷新托盘标签/菜单；
- 当 `capsule_auto_hide` 变更时刷新托盘标签/菜单，以便托盘可见性项立即正确；
- 保留完整 config 保存作为持久化普通设置页编辑的唯一路径。

新增一个用于持久化 patch 的前端 store action，例如：

```ts
applyPersistedConfigPatch(patch: Partial<AppConfig>): void
```

行为：

- 把 patch 合并进 `config`；
- 当 `savedConfig` 非 null 时，把同一 patch 合并进 `savedConfig`；
- 当 patch 包含 `ui_language` 时，在该 webview 中更新 i18n 与 `localStorage`；
- 保留 `config` 中无关的 dirty 字段；
- 把 `savedConfig` 作为被 patch 字段的持久化基线。

这是必需的，这样托盘/胶囊可见性变更不会抹掉未保存的设置编辑。

### 托盘标签

在新增可见性项之前先修复托盘语言查找：

- 从 `settings.json` 读取 `app_config.ui_language`，或使用加载 `AppConfig` 的共享辅助；
- 当存储缺失或损坏时保留回退到英文；
- 为两种可见性状态新增本地化标签。

语言变更：

- 语言选择可以为响应性立即更新前端状态；
- 持久化的托盘标签必须仅在语言通过 `update_config` 或另一个后端保存辅助保存后才刷新；
- 旧的仅前端的 `refresh_tray_labels` 调用不够，因为它可能在新语言持久化之前运行。

### 默认迁移

不要仅依赖 `#[serde(default)]` 来处理 `capsule_auto_hide`。

使用一个配置加载辅助来区分：

- 没有存储的 `app_config`：新安装默认值，包含 `capsule_auto_hide: true`；
- 存储的 `app_config` 带有显式 `capsule_auto_hide`：保留显式值；
- 存储的 `app_config` 缺失 `capsule_auto_hide`：遗留默认值，`capsule_auto_hide: false`。

## 实现要点

- `useCapsuleResize()` 应停止只依赖 `leftIdle` 与 `becameIdle`；它应把实际窗口可见性与计算出的 `shouldShowCapsule` 协调一致。
- 上下文菜单本身在打开时强制胶囊窗口可见。
- 右键菜单应在切换可见性后关闭。
- 隐藏用 lucide 的 `EyeOff`，保持可见用 `Eye`。
- 菜单文本必须在 `capsule.menu` 下本地化。
- 设置的 dirty-bar 仍可用于普通设置页编辑；胶囊菜单与托盘菜单是即时操作。
- 若设置页有未保存变更，外部胶囊可见性 patch 必须只更新可见性字段的持久化基线。

## 测试计划

Rust：

- `AppError::Quota` 不可重试。
- `AppError::Quota` 映射为 `stt_quota_exceeded`。
- 云端 STT 403 的 quota 码映射为 `AppError::Quota`。
- 云端 STT 403 的 quota 消息映射为 `AppError::Quota`。
- 云端 STT 403 的空、不可解析或非 quota body 映射为 `AppError::Auth`。
- 锁存的 STT 错误阻止为匹配会话发出无语音。
- 来自陈旧会话的锁存 STT 错误不影响当前会话。
- 真实空的成功 STT 仍可发出 `stt_no_speech_detected`。
- 托盘菜单为启用与禁用状态构建胶囊可见性项。
- 托盘语言查找读取 `app_config.ui_language`。
- 完整的 `update_config` 在 `capsule_auto_hide`、`max_recording_seconds` 或 `ui_language` 变更时发出 `config:patch`。
- 完整的 `update_config` 在持久化 `ui_language` 变更后刷新托盘标签/菜单。
- 完整的 `update_config` 在持久化 `capsule_auto_hide` 变更后刷新托盘标签/菜单。
- 配置加载把新安装默认 `capsule_auto_hide: true`。
- 配置加载保留已有的显式 `capsule_auto_hide` 值。
- 配置加载把缺失 `capsule_auto_hide` 的已有配置视为 `false`。
- 胶囊可见性保存辅助只 patch `capsule_auto_hide`。

前端：

- 每个 locale 都定义所有必需的 `errors` key。
- 胶囊右键菜单在自动隐藏关闭时显示 `Hide capsule when idle`。
- 胶囊右键菜单在自动隐藏开启时显示 `Keep capsule visible`。
- 胶囊右键菜单调用 `set_capsule_auto_hide`，而非完整 config 的 `updateConfig`。
- `config:patch` 更新 `config.capsule_auto_hide` 与 `savedConfig.capsule_auto_hide`。
- `config:patch` 从完整设置保存更新胶囊相关的持久化设置，包括 `max_recording_seconds`。
- 带 `ui_language` 的 `config:patch` 在主窗口与胶囊 webview 中更新 i18n 与 `localStorage`。
- `config:patch` 保留无关的 dirty config 字段。
- 当 patch 字段在本地也是 dirty 时，持久化 patch 对该字段胜出，并更新同一字段的 `savedConfig`。
- 自动隐藏可见性逻辑在空闲时已启用自动隐藏则隐藏。
- 自动隐藏可见性逻辑在空闲时出现错误则显示。
- 自动隐藏可见性逻辑在空闲时错误清除后再次隐藏。
- 现有的录音取消按钮测试继续通过。
- 引导文案在新安装默认自动隐藏时，不承诺总是可见的空闲胶囊。

手工：

- 云端免费 quota 耗尽时，录音显示本地化 quota 消息，而非无语音。
- 真实静音录音且 quota 可用时，录音显示本地化无语音。
- 启用自动隐藏时，空闲胶囊消失；热键录音使其以波形与计时器重新出现。
- 右键菜单可在不改变无关设置的情况下启用自动隐藏。
- 系统托盘可恢复被隐藏的空闲胶囊。
- 变更语言从持久化 `app_config.ui_language` 更新托盘标签。
- 从设置保存 `Hide capsule when idle` 无需重启即可更新胶囊窗口。
- 打开设置、做无关的未保存编辑，然后从托盘切换胶囊可见性，不抹掉未保存编辑。

## 发布与沟通

发布说明应将此描述为桌面 UX/错误加固修复：

- 云端 STT quota/auth 错误现在显示正确的本地化消息。
- 空语音不再用作云端失败的回退消息。
- 桌面胶囊可在空闲时从右键菜单隐藏，并从托盘/设置恢复。
- 新安装默认隐藏空闲胶囊，而已有用户保留其持久化偏好。

## 已确认的 Spec 评审

本修订中确认修复的问题：

- P1：胶囊菜单的完整 config 持久化可能覆盖来自另一个 webview 的较新设置。修订设计需要一个部分 Rust 命令。
- P1：外部托盘/胶囊保存可能抹掉 dirty 设置。修订设计需要一个持久化 patch action，只在 `config` 与 `savedConfig` 中更新 `capsule_auto_hide`。
- P1：自动隐藏未处理空闲到空闲的配置变更或空闲错误。修订设计定义了单一可见性公式与转换要求。
- P1：默认隐藏的新安装可能改变缺失该字段的遗留配置。修订设计需要显式的迁移行为。
- P2：托盘标签从错误的存储路径读取语言。修订设计需要 `app_config.ui_language`。
- P2：空或不可解析的 403 body 可能被误分类为 quota。修订设计禁止把 quota 作为回退。
- P2：引导文案可能与默认隐藏行为冲突。修订设计若新安装默认隐藏，则需要更新文案。
- P2：完整设置保存可能在持久化胶囊可见性或语言时不通知胶囊窗口或托盘。修订设计需要 `update_config` 发出相关 patch，并在持久化语言/可见性变更后刷新托盘标签。

澄清的实现约束：

- STT 错误锁存必须是会话感知的，并使用现有的陈旧会话守卫。
- 自动隐藏逻辑应暴露可测试的可见性决策，而非仅依赖手工窗口测试。

自审结果：

- 没有遗留占位符。
- 云端错误与胶囊可见性需求被分开，但共享一个发布范围。
- 设计避免了陈旧的完整 config 写入。
- 实现范围适合一个 TDD 计划。
