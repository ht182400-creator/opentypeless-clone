## 品牌规则

- `OpenTypeless` 是唯一面向用户的桌面产品名。
- `TalkMore` 不得作为桌面产品名出现在 README 文本、图片引用、alt 文本或说明中。
- 既有的历史文件名可保留在仓库中，但任何刷新后的 README 都不得渲染过时的 TalkMore 素材。
- 竞品名如 Typeless、Wispr Flow、Superwhisper 在用于事实定位时保留。
